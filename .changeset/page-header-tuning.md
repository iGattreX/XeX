`Header` gets a `density` prop: `comfortable` (the default, unchanged) or `compact` (less padding, a smaller title and a one-line subtitle), and a faint shadow under it. The theme dropdown's options use the same gradient swatches as the swatch picker, and its list now opens toward the side with room so it is no longer clipped on phones.
