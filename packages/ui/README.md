# @xex/ui

React components, app shell and `ThemeProvider` for the XeX design system.

```tsx
import { Button, Tabs, DataTable, ThemeProvider } from '@xex/ui'
```

- Peer dependencies: `react` and `react-dom` 19.
- Needs `@xex/tailwind-preset` in your Tailwind config and `@xex/tokens/styles.css` imported once. See the [repository README](../../README.md) for the full setup.
- Optional entry `@xex/ui/font-picker` adds a Google Fonts picker (it makes requests to Google Fonts and Fontsource).
